# MA60 股票筛选器 (Frontend)

本项目是一个基于 Vue 3 + Element Plus 的股票筛选器前端页面，用于筛选 MA60 日线级别波动率小于设定值的股票。

## 核心功能
- **时间范围选择**：支持最近一个月或两个月的筛选。
- **波动率限制**：默认筛选波动小于 0.07 (7%) 的股票。
- **自动化计算**：通过后端 API 获取实时数据并计算 MA60 指标。

## 技术栈
- **Vue 3** (Composition API)
- **Element Plus** (UI 组件库)
- **Vite** (构建工具)
- **Axios** (数据请求)

## 响应式设计
本项目采用了响应式设计，完美适配以下场景：
- **桌面客户端**：宽屏显示，多列布局。
- **H5/移动端**：自动切换为垂直布局，表格支持横向滚动，操作更便捷。

## 快速开始

### 1. 安装依赖
在项目根目录下执行：
```bash
npm install
```

### 2. 启动开发服务器
```bash
npm run dev
```

### 3. 后端集成
本前端默认通过 Vite 代理将 `/api` 请求转发至 `http://localhost:5000`。请确保您的 Flask 后端服务已启动并运行在 5000 端口。

## 筛选逻辑说明
1. **数据获取**：获取股票过去 90 天（或更多）的日线收盘价。
2. **MA60 计算**：计算 60 日移动平均线。
3. **波动率计算**：在选定的时间范围内（1个月或2个月），计算 MA60 的浮动。
4. **结果输出**：展示符合筛选条件的股票代码、名称及具体的波动率。
